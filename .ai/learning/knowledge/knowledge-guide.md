# Versa Coder — Knowledge Base Guide

---

## 1. Amaç

AI'ın **teknik bilgi tabanını genişletmesini** sağlayan modül.

---

## 2. Knowledge Türleri

| Tür | Tanım | Kaynak |
|-----|-------|--------|
| API Reference | API dokümantasyonu | Web scraping |
| Library Info | Kütüphane bilgisi | NuGet, GitHub |
| Best Practice | En iyi uygulamalar | Web araştırması |
| Domain Knowledge | Alan bilgisi | Proje analizi |
| Tool Knowledge | Tool kullanımı | Dokümantasyon |

```markdown
## Knowledge: [Konu]

- **İçerik:** [Bilgi]
- **Kaynak:** [URL veya dosya]
- **Güven:** [0.0-1.0]
- **Güncelleme:** [tarih]
```
