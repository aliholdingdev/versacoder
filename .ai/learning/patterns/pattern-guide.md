# Versa Coder — Pattern Learning Guide

---

## 1. Amaç

AI'ın **kod kalıplarını öğrenmesini ve tekrar uygulamasını** sağlayan learning modülü.

---

## 2. Pattern Türleri

| Tür | Tanım | Örnek |
|-----|-------|-------|
| Code Pattern | Tekrar eden kod yapısı | Repository pattern, CQRS handler |
| Naming Pattern | İsimlendirme kuralları | PascalCase class, camelCase variable |
| Architecture Pattern | Mimari yapı | Layered architecture, Clean Architecture |
| Error Pattern | Hata yönetimi | Try-catch, Result monad |
| Test Pattern | Test yapısı | Arrange-Act-Assert |

---

## 3. Pattern Kayıt Formatı

```markdown
## Pattern: [Pattern Adı]
- **Kategori:** [Code/Naming/Architecture/Error/Test]
- **Kalıp:** [Açıklama]
- **Örnek:** [Kod örneği]
- **Güven:** [0.0-1.0]
- **Kullanım Sayısı:** [n]
- **İlk Kayıt:** [tarih]
- **Son Kullanım:** [tarih]
```

---

## 4. Öğrenme Akışı

```
Kod İnceleme → Pattern Tanımla → Güven Hesapla → Kaydet → Gelecekte Kullan
```
