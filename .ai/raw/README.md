# raw/ — Ham Kaynak Klasörü

- Bu klasör **ham kaynak** içindir: makale, transkript, not, PDF, web klibi.
- Buradaki dosyalar **değiştirilmez, silinmez, sadece okunur.**
- Yeni kaynak eklenince **INGEST** işlemi çalıştırılır (bkz. [[../CLAUDE]] §9).

Ham kaynak buraya oldugu gibi konur; özet ve işlenmiş bilgi asla burada tutulmaz,
`sources/` ve `wiki/` altına yazılır.
